# Sistem Informasi Pemesanan Tiket Wisata Air Terjun Lubuk Hitam

## 1. Deskripsi Proyek

Aplikasi berbasis web untuk mendukung proses pemesanan tiket wisata Air Terjun Lubuk Hitam. Sistem ini dikembangkan sebagai proyek Sistem Informasi dengan menggunakan framework Laravel.

## 2. Tujuan

- Mempermudah proses pemesanan tiket wisata.
- Membantu pengelolaan data pengunjung dan transaksi.
- Mendukung pencatatan dan penyusunan laporan tiket.

## 3. Teknologi

- PHP
- Laravel
- MySQL atau database yang digunakan dalam konfigurasi proyek
- HTML, CSS, dan JavaScript sesuai implementasi

## 4. Fitur Aplikasi

- Pemesanan tiket wisata.
- Pengelolaan data pengunjung.
- Pengelolaan tiket dan transaksi.
- Pengelolaan informasi wisata.
- Laporan pemesanan.

Catatan: Daftar fitur perlu disesuaikan dengan fitur yang benar-benar tersedia pada aplikasi.

## 5. Cara Menjalankan Aplikasi

1. Unduh atau clone repository.
2. Jalankan `composer install`.
3. Salin `.env.example` menjadi `.env`.
4. Sesuaikan konfigurasi database.
5. Jalankan `php artisan key:generate`.
6. Jalankan migrasi database jika diperlukan.
7. Jalankan `php artisan serve`.
8. Buka `http://127.0.0.1:8000` di browser.
